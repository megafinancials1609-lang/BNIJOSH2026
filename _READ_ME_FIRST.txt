  server count for that chapter. If the save would LOWER the count (i.e. erase
  registrations), the page refuses and tells the user to refresh first.
- Normal registrations (which increase the count) work exactly as before.
- This makes the ICONS/MANTRA-style wipes impossible from any of these pages,
  without anyone needing to change how they work.
- The 5 unlock edits (Jyoti Jain, Sourabh, Sarfaraj, Vaibhav+RAHUL, Hallmark 3)
  are already baked into these files too.

HOW TO DEPLOY:

  replacing the existing ones. Then hard-refresh (Ctrl+Shift+R).
- Do NOT upload _READ_ME_FIRST.txt (optional).
